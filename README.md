# 📊 Global Superstore Sales Analysis

## 📌 Project Overview

This project analyzes Global Superstore sales data using SQL and Power BI to understand sales performance, profitability, customer behavior, and product trends.

The dashboard presents key business metrics and interactive visualizations to support data-driven decision-making.

## 🎯 Objectives

* Analyze overall sales and profit performance.
* Compare sales across markets and regions.
* Identify top-performing customers and products.
* Understand category-wise and sub-category-wise sales.
* Analyze shipping modes and monthly sales trends.
* Build an interactive Power BI dashboard.

## 🛠️ Tools & Technologies

* **MySQL** — Data analysis using SQL queries.
* **Microsoft Power BI** — Dashboard development and visualization.
* **DAX** — Calculated measures and KPI analysis.

## 📈 Key Performance Indicators (KPIs)

* Total Sales
* Total Profit
* Total Orders
* Total Customers
* Profit Margin

## 📊 Dashboard Features

* Sales by Market
* Sales by Region
* Sales by Category and Sub-Category
* Sales by Customer
* Sales by Product
* Monthly Sales Trends
* Shipping Mode Analysis
* Interactive filters for Region, Market, Year, and Category

## 💡 Business Insights

The dashboard helps explore:

* Which markets and regions contribute more to sales.
* Which products and customers perform well.
* How sales change over time.
* How shipping modes relate to sales performance.
* How sales and profit vary across product categories.

*Specific findings should be added after validating the results in the dashboard.*

## 📁 Project Files

* `SQL_Queries.sql` — SQL queries used for analysis.
* `Global_Superstore_Dashboard.pbix` — Power BI dashboard file.
* `Dashboard_Screenshot.png` — Dashboard preview.

## 🚀 How to Use

1. Download or clone this repository.
2. Open `SQL_Queries.sql` in MySQL Workbench.
3. Configure the database and table names to match your dataset.
4. Open `Global_Superstore_Dashboard.pbix` using Power BI Desktop.
5. If prompted, update the data source connection to your local dataset.
